# 屏幕数字比较识别工具（比大小自动作答）

自动识别屏幕上的「数字 ? 数字」比较题（如 `5 ? 3`、`13 ? 12`），用**真实鼠标模拟书写**把 `>` `<` `=` 画到答题区域——把屏幕当触控屏，带随机晃动、弧线弯曲、变速模拟人手，用于通过人机验证。

## 特性

- **内置数字识别**：纯 OpenCV 模板匹配（20+ 系统字体），无需安装任何外部 OCR 引擎
- **极速自动监测**：识别框内出现新题 → **约 75ms** 自动识别并划线，全自动做题
- **补划兜底**：划线后软件若没反应（画面未变化），每 **0.8 秒**自动补划一次，直到软件吃下/切题；识别读不出时每 **2.5 秒**重试
- **真实鼠标书写**：模拟「按下 → 平滑拖动 → 抬起」，`>` `<` 整体一笔画完，`=` 两笔
- **人手机感**：随机晃动（正弦调制，两端精确收笔）+ 弧线弯曲 + 变速 + 位置偏移
- **L 键现场抓帧**：按 L 瞬间重新截屏识别当前题目，绝不使用上一题的缓存答案
- **防误判**：`?` 作为分隔符（`13?12` 绝不会读成 `131>2`）、三位数粘连拒绝、同题去重
- **长跑稳定**：显式释放每帧 + 定期 GC + 每 100 题报告内存
- **框可拖动缩放**：识别框/书写框 1:1 精确跟随，位置自动记忆

## 安装

仅需 4 个库，无任何外部程序（Windows）：

```bash
pip install -r requirements_simple.txt
```

## 使用

```bash
python main_simple.py
```

1. **拖动红色识别框** → 套住题目（如 "5 ? 3"）
2. **拖动青色书写框** → 对准答题位置
3. **自动模式（默认开启）**：新题出现 → 自动识别并划线，无需任何操作
4. 需要手动兜底时按 **L** 键 → 现场识别并划线

> 触发键默认是 **L**（`HOTKEY_VK = 0x4C`），可在 `main_simple.py` 顶部改成其他键。

### 自动监测工作方式

```
新题出现（画面变化）→ 10ms 稳定确认 → 识别 → ~75ms 内划出
    └─ 软件没反应（画面没变）→ 每 0.8s 补划，直到软件吃下/切题
    └─ 识别读不出 → 每 2.5s 重试，5 次后转入 0.8s 补划循环
```

补划循环只在**画面发生变化**（软件判题打勾 / 切到下一题）时停止，不会提前断。

## 控制面板

| 按钮 | 功能 |
|------|------|
| ⏸ | 暂停 / 继续（暂停时自动监测和 L 键都不动作） |
| 🔒 / 🔓 | 锁定（框点击穿透，不挡鼠标）/ 解锁（调整位置） |
| 📌 | 置顶 / 取消置顶 |
| ? | 使用说明 |
| ✕ | 关闭程序 |

快捷键：**L** 划线、**ESC** 退出

## 可调参数（`main_simple.py` 顶部）

| 参数 | 默认 | 说明 |
|------|------|------|
| `HOTKEY_VK` | `0x4C` (L) | 手动划线触发键 |
| `confirm_delay` | `0.01` | 画面变化后的稳定确认时间（秒） |
| `redraw_at` 间隔 | `0.8` | 划线后软件没反应时的补划间隔（秒） |
| `retry_delay` | `2.5` | 识别失败后的重试间隔（秒） |
| `max_retries` | `5` | 识别失败最大重试次数 |
| `max_number` | `199` | 题目数字上限（超范围 = 粘连误读，拒绝划线） |
| `confidence` | `0.62` | 识别置信度阈值（调低更易识别但更易误判） |

## 故障排除

| 问题 | 解决 |
|------|------|
| 划线没反应 | 目标程序是否管理员运行？本工具也要**以管理员身份运行** |
| 画到别的位置 | 解锁（🔓）拖动青色框到正确位置，再锁定 |
| 识别不准 | 红色框完整框住两个数字；可降低 `confidence` |
| 线太细/看不清 | 把青色框拉大，符号按框尺寸放大 |
| 同一题反复划线 | 说明软件一直没吃下鼠标输入，看控制台日志确认 |

## 技术说明

| 技术 | 说明 |
|------|------|
| 全局热键 | `WH_KEYBOARD_LL` 低层键盘钩子（ctypes），无需窗口聚焦 |
| 鼠标模拟 | `SetCursorPos` + `mouse_event`，多步插值平滑笔迹 |
| 点击穿透 | `WS_EX_TRANSPARENT`，锁定时框不拦截鼠标 |
| DPI 感知 | 进程级 DPI Aware，tkinter/截图/鼠标坐标统一物理像素 |
| 数字识别 | 20+ 字体模板（IoU + CCOEFF），5/6 用顶部横杠密度判别 |
| 屏幕捕获 | `mss` 极速路径直转 BGR，识别框区域级截图 |

## 注意事项

- 仅支持 **Windows**（依赖 ctypes 全局热键与真实鼠标事件）
- 如果目标程序以管理员身份运行，本工具需同样以管理员运行，否则模拟鼠标事件会被系统拦截（UIPI）
- L 键是全局监听，任何程序里按 L 都会触发划线（按住 0.5 秒内的连发会被忽略）
