# 屏幕数字识别书写工具

两个脚本，一个比大小、一个做四则运算，都用**真实鼠标模拟书写**把答案画到屏幕上（把屏幕当触控屏），并带随机晃动通过人机验证。

## 两个脚本

| 脚本 | 用途 | 写法 |
|------|------|------|
| `main_simple.py` | 比较大小（`5 ? 3` → 画 `>`） | 鼠标画出 `>` `<` `=` |
| `main_calc.py` | 四则运算（`3 + 4` → 写 `7`） | 鼠标**手写出结果数字** |

**共同点**（两个脚本都有）：
- **无缓存**：按 L 键现场抓帧识别，识别不到**就不执行任何操作**
- **L 键现场抓帧**：按下瞬间重新截屏识别当前题目，不会用上一题的答案
- **真实鼠标书写**：模拟「按下 → 平滑拖动 → 抬起」，每笔一笔画完
- **随机晃动**：随机数微晃动 + 弧线弯曲 + 变速 + 位置偏移，模拟人手
- **长跑内存管理**：显式释放每帧 + 定期 gc + 每 100 题报告内存
- **终端打印题目**：每次书写打印 `[划线] 题目: 13 ? 14 → 13 < 14`

## main_simple.py（比大小）

- 识别题目中间 `?` 并作为**分隔符**（`13?12` 绝不会读成 `131>2`）
- 没有问号自动回退到间距分组
- `>` `<` 整体一笔画完，`=` 两笔

## main_calc.py（四则运算 + 求未知数）

- 识别 `+ - × ÷`（也支持 `* / x X` 及全角 `＋－＝？` 变体）
- **直接计算**：`3 + 4` → 写 `7`
- **求未知数**（问号在任意位置）：
  - `? + 3 = 5` → 2、`5 - ? = 2` → 3、`6 × ? = 12` → 2、`12 ÷ ? = 3` → 4
  - `3 + 4 = ?` → 7（未知在结果）
  - 问号支持 `?`/`？`/空框 `□`/纯空白位
  - 紧凑排版（`3+4=?`）也能正确切分
- 除法**除不尽或除数为 0 时不写答案**（绝不写错的）
- 支持负数（`3 - 8` → 写 `-5`）、多位数（`12 × 12` → 写 `144`）
- 结果每位数字在答题框内居中排版，每个数字按手写笔画写出

## 使用流程

```bash
# 1. 安装依赖（仅 4 个库，无任何外部程序）
pip install -r requirements_simple.txt

# 2. 运行（二选一）
python main_simple.py   # 比大小
python main_calc.py     # 四则运算
```

1. **拖动红色识别框** → 套住题目（如 "5 ? 3" 或 "3 + 4"）
2. **拖动青色书写框** → 对准答题位置
3. **按 L 键** → 现场识别、计算，真实鼠标写出答案
4. 题目切换后再次按 L → 写下一题

> 触发键默认是 **L**（`HOTKEY_VK = 0x4C`），可在文件顶部改成其他键。

## 控制面板

| 按钮 | 功能 |
|------|------|
| ⏸ | 暂停 / 继续（暂停时按 L 不划线） |
| 🔒 / 🔓 | 锁定（框点击穿透，不挡鼠标）/ 解锁（调整位置） |
| 📌 | 置顶 / 取消置顶 |
| ? | 使用说明 |
| ✕ | 关闭程序 |

快捷键：**L** 划线、**ESC** 退出

## 关键技术

| 技术 | 说明 |
|------|------|
| 全局热键 | `WH_KEYBOARD_LL` 低层键盘钩子（ctypes），无需窗口聚焦 |
| 鼠标模拟 | `SetCursorPos` + `mouse_event` 按下/抬起，多步插值平滑笔迹 |
| 人手机感 | 随机晃动（正弦调制，两端精确收笔）+ 弧线弯曲 + 随机速度 + 位置微偏移 |
| 一笔画完 | 每笔「按下 → 连续拖动 → 抬起」中途绝不松开；`>` `<` 整体一笔 |
| 点击穿透 | `WS_EX_TRANSPARENT`，锁定时框不拦截鼠标；划线前也会临时穿透 |
| DPI 感知 | 进程级 DPI Aware，tkinter/截图/鼠标坐标统一物理像素 |
| 数字识别 | 内置 20+ 字体模板匹配（IoU + CCOEFF），无需安装 OCR 引擎 |

## 注意事项

- **管理员权限**：如果目标程序以管理员身份运行，本工具需同样以管理员运行，否则模拟的鼠标事件会被系统拦截（UIPI）
- **触发键冲突**：L 键是全局监听，任何程序里按 L 都会触发划线（按住 0.5 秒内的连发会被忽略）
- **识别不了时**：按 L 会在控制台提示"尚未识别到题目中的两个数字"，此时调整红色框大小或位置

## 故障排除

| 问题 | 解决 |
|------|------|
| 划线没反应 | 目标程序是否管理员运行？本工具也要管理员运行 |
| 画到别的位置 | 解锁（🔓）拖动青色框到正确答题位置，再锁定 |
| 识别不准 | 红色框完整框住两个数字；可降低 `confidence`（0.4） |
| 线太细/看不清 | 把青色框拉大，符号会按框尺寸放大 |
